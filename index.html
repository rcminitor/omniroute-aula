Agentes de IA & OmniRoute no Laboratório

Roteiro pedagógico completo para a aula de laboratório: entenda o que são agentes de IA, por que o "grátis ilimitado" não existe, como instalar as ferramentas, ligar o servidor, cadastrar suas chaves e finalmente executar o Claude Code com roteamento automático de fallback.

1 O que é um Agente de IA? (Entenda antes de instalar)

Antes de tocar no teclado, você precisa entender o que vamos fazer hoje. Não é usar um chatbot normal. Hoje vamos montar um sistema de agentes autônomos que age, não apenas responde.

Analogia: Chatbot vs. Agente

Um chatbot comum (ex: ChatGPT na tela) é como um chef que te manda a receita por mensagem de texto. Você que tem que ir para a cozinha e cozinhar.

Um Agente de IA é como um chef que entra na sua cozinha, abre a geladeira, lê os ingredientes, acende o fogão, cozinha o prato e coloca na mesa. Você só pede: "Quero uma massa ao molho pesto" e espera pronto.

As 3 ferramentas que vamos usar hoje:

Agente Principal

Claude Code

É o agente que fica na "tela preta" (terminal/PowerShell). Você conversa com ele em português, pede para criar código, analisar arquivos, debugar erros - e ele age diretamente no computador: cria pastas, escreve arquivos, roda testes, tudo sozinho.

📌 Instalado via npm e roda no terminal.
📌 Por padrão usa a API paga da Anthropic - e por isso que vamos usar o OmniRoute!

Roteador Local

OmniRoute

É um programa que fica rodando no seu computador como um servidor local (na porta 20128). Ele intercepta os pedidos do Claude Code e os redireciona para provedores de IA gratuitos, como Google Gemini e Groq.

📌 Tem um painel visual no navegador (localhost:20128).
📌 Faz fallback automático: se um provedor travar, muda para o próximo.

Provedores Externos

Google Gemini & Groq

São os servidores de IA que realmente "pensam". O Gemini fica na nuvem da Google e o Groq em chips ultrarrápidos nos EUA. Ambos têm cotas gratuitas oficiais suficientes para usar em sala de aula.

📌 Você precisa criar uma conta gratuita em cada site.
📌 Cada um te dá uma chave de API (senha secreta) que vamos configurar.

Como tudo se conecta (fluxo completo):

→
Você digita no Claude Code (terminal)

Exemplo: "Crie uma página HTML com formulário de login"

▼ Claude Code envia o pedido para localhost:20128
→
OmniRoute (rodando na sua máquina, porta 20128)

Recebe o pedido, olha qual provedor está disponível, e encaminha.

▼ Encaminha para Google Gemini (1ª prioridade)
→
Google Gemini / Groq Cloud (IA na nuvem)

Processa o pedido e devolve a resposta em segundos.

▼ Retorna para o Claude Code → Claude age no seu computador
✅
Resultado: arquivo criado no seu computador!

Claude cria o arquivo index.html, escreve o código - tudo sozinho.

2 A Falácia do "Almoço 100% Grátis" & Erro 429

Muitos vídeos na internet prometem "Claude Code ilimitado e 100% grátis para sempre". Na prática, isso é uma ilusão técnica. Você precisa entender por que antes de frustrar-se no laboratório.

Por que o "100% grátis na nuvem" trava? (O Erro 429)

Rodar Inteligência Artificial exige supercomputadores com placas de vídeo caras (GPUs H100 da NVIDIA). Plataformas como o OpenRouter dão modelos :free apenas para pequenos testes. Como o agente faz 40+ chamadas em 5 minutos, a cota diária zera e aparece o erro:

API Error: Request rejected (429) - Rate limit exceeded: free-models-per-day

A Solução da Aula: Roteamento com Fallback

Para a sua aula não travar, usamos o OmniRoute conectando múltiplos provedores independentes. Se a cota de um zerar, ele pula para o outro automaticamente:

1º
Google Gemini (Google AI Studio) Cota gratuita oficial e generosa direto da Google
Principal
▼ Se o Gemini bater o limite 429...
2º
Groq Cloud (Llama 3.3 70B) Assume imediatamente em chips ultrarrápidos - resposta em menos de 1 segundo
Fallback
▼ Se ambos estiverem no limite...
3º
DeepSeek / Modelo de Centavos (opcional) Rede de segurança - custo de centavos para quem tiver R$ 5 de crédito
Emergência

Resumo para a aula: Você vai criar uma conta gratuita no Google AI Studio e no Groq, pegar a chave de cada um e cadastrar no OmniRoute. Isso cria o combo que nunca trava - mesmo que uma cota estoure, o outro assume na hora.

3 Dicas de Sobrevivência (Antes de Mexer no Teclado)

Se você nunca usou o terminal ou não tem computador em casa, guarde estas 4 regras práticas:

Como colar no terminal

Clique no botão de copiar. Na tela preta (PowerShell), basta dar um clique com o botão direito do mouse que o texto cola sozinho.

O segredo das 2 janelas

O OmniRoute precisa de duas janelas pretas abertas: Janela 1 (motor ligado) e Janela 2 (conversa com o Claude). Não tente fazer tudo em uma janela só!

A pasta invisível

Pastas com ponto na frente (ex: .claude) ficam invisíveis no Windows. Se você não vir a pasta no Explorer, ela NÃO sumiu, está oculta.

Texto amarelo não é erro

Avisos amarelos do npm warn são apenas informações. Você só deve se preocupar se o terminal fechar ou der uma mensagem vermelha.

4 Mão na Massa: Instalando Ferramentas e Criando o Projeto

Agora vamos começar a preparar o computador. Siga os passos na ordem exata:

Passo 0 · Pré-requisitos

Abrir o PowerShell e Testar se o Node.js existe

Como Abrir o PowerShell
Pressione a tecla Windows no teclado → Comece a digitar powershell → Clique em "Windows PowerShell" nos resultados. Uma janela preta vai abrir.

Dentro da janela preta, copie e cole o comando abaixo e pressione Enter:

PowerShell - Teste de Verificação 
node -v
Se apareceu um número (ex: v20.x ou v22.x):

O Node.js e o npm já estão instalados! Pule direto para o Passo 1.

Se deu texto vermelho (Comando não reconhecido):

O computador não tem Node.js. Instale com o comando abaixo:

PowerShell - Instalação do Node.js 
winget install OpenJS.NodeJS.LTS
Atenção: Se você acabou de instalar o Node.js, feche o PowerShell e abra de novo para ele reconhecer o npm.
Passo 1 · Instalar Pacotes

Instalar o Claude Code e o OmniRoute

Instale os dois programas necessários via npm:

PowerShell 
npm install -g @anthropic-ai/claude-code
npm install -g omniroute
Resultado esperado: Vários downloads vão passar na tela e terminar com added N packages.
Passo 2 · Criar Pasta do Projeto

Criar a Pasta Isolada do Projeto

Copie e cole para criar a pasta da aula e a subpasta oculta .claude:

PowerShell 
mkdir C:\Users\$env:USERNAME\Projetos\meu-projeto-ia -Force
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
mkdir .claude -Force
Resultado esperado: O caminho do terminal vai mudar para PS C:\Users\...\meu-projeto-ia>.
Passo 3 · Proteger Dados Sensíveis

Criar o arquivo de Proteção (.gitignore)

Gera o arquivo que impede que senhas e dados locais subam para a internet:

PowerShell 
@'
.claude/settings.local.json*
*.env
*.log
*.sqlite*
'@ | ForEach-Object { [IO.File]::WriteAllText("$PWD\.gitignore", $_) }
Passo 4 · Conectar ao OmniRoute

Configurar o Claude Code para usar o OmniRoute

Cria a configuração que conecta o Claude Code ao gateway local (porta 20128):

PowerShell 
@'
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "sk-omniroute-local-token",
    "ANTHROPIC_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gratuitos",
    "CLAUDE_CODE_SUBAGENT_MODEL": "gratuitos",
    "ENABLE_CLAUDEAI_MCP_SERVERS": "false"
  },
  "model": "gratuitos",
  "disableClaudeAiConnectors": true
}
'@ | ForEach-Object { [IO.File]::WriteAllText("$PWD\.claude\settings.local.json", $_) }
Pronto! As ferramentas estão instaladas. Agora vamos ligar o servidor OmniRoute antes de continuar.

5 Ligar o OmniRoute (Fazer o Servidor Funcionar)

Antes de cadastrar as chaves ou usar o Claude, você precisa ligar o servidor OmniRoute. Sem ele ligado, nada funciona. Este é o "motor" que precisa estar sempre rodando.

IMPORTANTE: O servidor precisa estar ligado em uma janela do terminal dedicada que você NUNCA pode fechar enquanto está usando o Claude Code. Pense nela como o motor de um carro - se apagar, o carro para.

Passo 5.1 · Iniciar Servidor

Iniciar o servidor OmniRoute

Abra uma nova janela do PowerShell (Windows + digitar powershell) e rode:

PowerShell (Janela 1 - Mantenha aberta!) 
omniroute serve
Esta janela vai ficar "parada" mostrando logs. Isso é normal. NÃO FECHE essa janela!

Sinal de que funcionou: Você verá na tela algo como Server started on http://localhost:20128. Quando aparecer isso, o motor está ligado!

Passo 5.2 · Painel Visual

Abrir o Painel do OmniRoute no Navegador

Com o servidor ligado, abra seu navegador (Chrome, Edge ou Firefox) e acesse:

Abrir Painel OmniRoute (localhost:20128) ↗
O que você vai ver na tela do painel
Uma interface escura com o logo do OmniRoute. No menu da esquerda você verá as opções: Dashboard, Providers, Combos, e Logs. Isso significa que o servidor está funcionando corretamente!

6 Pegar as Chaves Gratuitas de API

Agora que o servidor está rodando, vamos buscar as chaves nos sites oficiais. Cada chave é como uma senha que autoriza o OmniRoute a usar os modelos de IA.

Dica: Abra os dois sites abaixo em abas separadas do navegador, copie as chaves e deixe um bloco de notas (Notepad) aberto para colar temporariamente. Você vai precisar das duas chaves no próximo passo.

G

1. Google Gemini API

100% Gratuito Oficial

Onde clicar no site (passo a passo):

1
Acesse o site e faça login com sua conta Gmail (botão azul no canto superior direito).
2
No menu da esquerda, clique em Get API key
3
Clique no botão Create API key que aparece no centro da página.
4
Selecione "Create API key in new project" e clique em Create.
5
Copie o código que aparece (começa com AIzaSy...). Guarde no Bloco de Notas!
Abrir Google AI Studio ↗
⚡

2. Groq Cloud (Llama 3)

Ultra-Rápido & Grátis

Onde clicar no site (passo a passo):

1
Acesse o site e clique em Sign In no canto superior direito. Use Google ou GitHub para entrar.
2
No menu lateral da esquerda, clique em API Keys.
3
Clique no botão Create API Key na parte superior.
4
Em "Name", escreva aula-ifce e clique em Submit.
5
Copie o código (começa com gsk_...). Salve no Bloco de Notas - ele só aparece uma vez!
Abrir Groq Cloud ↗

7 Cadastrar Provedores e Criar o Combo no Painel

Agora vamos entrar no painel do OmniRoute, colar as chaves e criar o Combo de Fallback. Lembre-se: o servidor precisa estar ligado (Seção 5)!

Abrir Painel OmniRoute (localhost:20128) ↗
Passo 7.1 · Cadastrar Provedores

Entrar na tela de Providers e Cadastrar os Provedores

Você está no painel do OmniRoute
Olhe para o menu lateral da esquerda. Você verá opções como Dashboard, Providers, Combos, Logs. Clique em Providers.
1
Na tela de Providers, clique no botão + Add Provider.
2
No campo Provider Type, selecione "Google Gemini" no menu suspenso.
3
No campo API Key, cole sua chave do Google (começa com AIzaSy...).
4
Clique no botão Save ou Connect. Um ícone verde ✅ deve aparecer indicando que está conectado.

Agora repita o processo para o Groq: Clique novamente em + Add Provider, selecione "Groq", cole a chave gsk_... e clique em Save.

Passo 7.2 · Criar Combo

Criar o Combo "gratuitos" (Roteamento com Fallback)

Navegue para a tela de Combos
No menu lateral da esquerda, clique em Combos.

O combo é a lista de prioridades que faz o transbordo automático se um provedor travar:

1
Clique no botão + Create Combo.
2
Em Combo Name, digite exatamente: gratuitos (tudo minúsculo, sem espaço).
3
Em Strategy, escolha: fill-first (tenta o 1º, se falhar pula pro 2º).
4
Clique em + Add Model e selecione/digite gemini-2.0-flash (1ª prioridade).
5
Clique novamente em + Add Model e selecione/digite groq/llama-3.3-70b-versatile (2ª prioridade).
6
Clique em Save Combo e depois ative-o clicando no toggle para "Enabled".
Resultado esperado: O combo "gratuitos" aparece na lista com status Active/Enabled. Isso significa que o roteamento automático com fallback está configurado!
Passo 7.3 · Testar Provedores

Testar se os Provedores estão Respondendo

Antes de abrir o Claude Code, rode este comando em uma nova janela do PowerShell:

PowerShell - Teste de Saúde dos Provedores 
omniroute providers test-all
Resultado esperado: Deve aparecer OK main (gemini): provider test passed e OK main (groq): provider test passed em verde!

8 Ligar e Rodar o Claude Code

Com tudo testado e verificado, vamos colocar tudo para rodar em 2 passos simples:

Verifique antes de continuar: A Janela 1 (com omniroute serve) ainda está aberta? Se tiver fechado por acidente, abra novamente e rode omniroute serve antes de continuar.

Passo 8.1 · Abrir Nova Sessão

Abrir uma Nova Janela e Rodar o Claude Code

1. Pressione a tecla Windows e abra uma nova janela do PowerShell (a Janela 1 com o OmniRoute deve continuar aberta!).
2. Nesta nova janela, entre na pasta do projeto e chame o claude:

PowerShell (Janela 2 - Para conversar com Claude) 
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
claude
Resultado final com sucesso: O Claude Code abrirá mostrando o rostinho laranja e gratuitos with high effort - pronto para você conversar!
Passo 8.2 · Primeiro Teste

Primeiro Teste: Pedir ao Claude para Criar um Arquivo

Com o Claude Code aberto e funcionando, vamos fazer um primeiro teste simples. Digite o pedido abaixo e pressione Enter:

Terminal Claude Code - Digite isto 
Crie um arquivo chamado ola.txt com o texto "Olá, Agente! Funcionou!" dentro.

Observe o que vai acontecer: O Claude vai agir autonomamente - você verá ele criar o arquivo, escrever o conteúdo e confirmar. Depois abra o Explorador de Arquivos e procure o arquivo ola.txt na pasta meu-projeto-ia para confirmar!

* Transfiguring... (processando seu pedido)

Olá! Como posso ajudar você no seu projeto de programação hoje?

auto mode on (shift+tab to cycle) · esc to interrupt · / for commands

Comandos que você vai usar durante a aula:

* Transfiguring...

Processando: É a animação normal do Claude Code indicando que ele está processando. Aguarde - não aperte nada!

/clear

Ficar mais rápido: Se a conversa começar a demorar, digite /clear no terminal para limpar o histórico e acelerar as respostas.

/exit

Sair: Para fechar o Claude Code, digite /exit ou pressione Ctrl+C.

omniroute providers test-all

Verificar status: A qualquer momento, rode este comando em uma nova janela para checar o status dos provedores.
