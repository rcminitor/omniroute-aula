Agentes de IA & OmniRoute no Laboratório

Roteiro pedagógico completo para a aula de laboratório: entenda as ferramentas, a realidade de custos em IA, prepare seu ambiente, cadastre as chaves no momento certo e execute o Claude Code.

1 🤖 As Ferramentas da Aula (O que vamos usar hoje?)

Hoje não vamos usar um chat comum de copiar e colar. Vamos usar um Agente de Desenvolvimento Autônomo que opera diretamente na máquina do laboratório:

🤖 Claude Code

O cérebro da aula. É um assistente que roda na tela preta (terminal), lê seus arquivos de código, cria novos arquivos e testa se tudo está funcionando.

🔀 OmniRoute

O roteador da aula. Um programa local que fica na porta 20128 recebendo os pedidos do Claude Code e escolhendo qual IA gratuita vai responder.

🟢 Provedores de IA

As empresas que fornecem os modelos de linguagem gratuitos oficiais (Google Gemini e Groq Cloud com Llama 3).

2 💸 A Falácia do "Almoço 100% Grátis" & Erro 429

Muitos vídeos na internet prometem "Claude Code ilimitado e 100% grátis para sempre". Na prática, isso é uma ilusão técnica.

⚠️ Por que o 100% grátis na nuvem trava? (O Erro 429)

Rodar Inteligência Artificial exige computadores caríssimos com supercomputadores (GPUs H100). Plataformas como o OpenRouter dão modelos :free apenas para pequenos testes. Como o agente faz 40 chamadas em 5 minutos, a cota diária zera e aparece o erro:

API Error: Request rejected (429) · Rate limit exceeded: free-models-per-day

A Solução da Aula: Roteamento com Fallback (Transbordo)

Para a sua aula não travar no meio do exercício, nós usamos o OmniRoute conectando múltiplos provedores independentes. Se a cota de um zerar, ele pula para o outro sozinho:

1
Google Gemini (Google AI Studio)

1ª Escolha: Cota gratuita oficial e generosa direto da Google.

▼ (Se a cota do Gemini bater limite 429)
2
Groq Cloud (Llama 3.3 70B)

2ª Escolha: Assume imediatamente em chips ultrarrápidos.

▼ (Se ambos estiverem ocupados)
3
DeepSeek / Modelo de Centavos

Rede de segurança para quem tiver R$ 5 de créditos.

3 🚨 Regras de Sobrevivência (Antes de Mexer no Teclado)

Se você nunca usou o terminal ou não tem computador em casa, guarde estas 4 regras práticas:

🖱️ Como colar no terminal

Clique no botão roxo de copiar. Na tela preta (PowerShell), basta dar um clique com o botão direito do mouse que o texto cola sozinho.

🪟 O segredo das 2 janelas

O OmniRoute precisa de duas janelas pretas abertas: Janela 1 (motor ligado) e Janela 2 (conversa com o Claude). Não tente fazer tudo em uma janela só!

👻 A pasta invisível

Pastas com ponto na frente (ex: .claude) ficam invisíveis no Windows. Se você não vir a pasta no Explorer, ela NÃO sumiu, está oculta.

🟡 Texto amarelo não é erro

Avisos amarelos do npm warn são apenas informações. Você só deve se preocupar se o terminal fechar ou der uma mensagem vermelha.

4 💻 Mão na Massa: Instalando Ferramentas e Criando o Projeto

Agora vamos começar a preparar o computador. Siga os passos na ordem exata:

PASSO 0 (OBRIGATÓRIO)

Testar se o Node.js e o npm existem na máquina

O comando npm não existe sozinho; ele vem dentro do Node.js. Abra o PowerShell (tecla Windows + digite powershell) e teste:

PowerShell - Teste de Verificação 
node -v
✅ Se apareceu um número (ex: v20.x ou v22.x):

O Node.js e o npm já estão instalados! Pule direto para o Passo 1.

❌ Se deu texto vermelho (Comando não reconhecido):

O computador não tem Node.js. Instale com o comando abaixo:

PowerShell - Instalação do Node.js 
winget install OpenJS.NodeJS.LTS
⚠️ Atenção: Se você acabou de instalar o Node.js, feche o PowerShell e abra de novo para ele reconhecer o npm.
PASSO 1

Instalar o Claude Code e o OmniRoute

Instale os dois programas necessários via npm:

PowerShell 
npm install -g @anthropic-ai/claude-code
npm install -g omniroute
Resultado esperado: Vários downloads vão passar na tela e terminar com added N packages.
PASSO 2

Criar a Pasta Isolada do Projeto

Copie e cole para criar a pasta da aula e a subpasta oculta .claude:

PowerShell 
mkdir C:\Users\$env:USERNAME\Projetos\meu-projeto-ia -Force
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
mkdir .claude -Force
Resultado esperado: O caminho do terminal vai mudar para PS C:\Users\...\meu-projeto-ia>.
PASSO 3

Criar o arquivo de Proteção (.gitignore)

Gera o arquivo que impede que senhas e dados locais subam para a internet:

PowerShell 
@'
.claude/settings.local.json*
*.env
*.log
*.sqlite*
'@ | Out-File -FilePath .gitignore -Encoding utf8
PASSO 4

Configurar o Claude Code para usar o OmniRoute

Cria a configuração que conecta o Claude Code ao gateway local (porta 20128):

PowerShell 
@'
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "sk-omniroute-local-token",
    "ANTHROPIC_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gratuitos",
    "CLAUDE_CODE_SUBAGENT_MODEL": "gratuitos",
    "ENABLE_CLAUDEAI_MCP_SERVERS": "false"
  },
  "model": "gratuitos",
  "disableClaudeAiConnectors": true
}
'@ | Out-File -FilePath .claude\settings.local.json -Encoding utf8

5 🔑 Chegou a Hora: Pegar as Chaves Gratuitas de API

Agora que a estrutura do seu projeto já está pronta, vamos pegar as chaves nos sites oficiais e cadastrar no OmniRoute. Clique nos botões abaixo:

G

1. Google Gemini API

100% Gratuito Oficial

Onde clicar no site:

  1. Faça login com seu Gmail normal.
  2. Clique no botão azul "Get API key".
  3. Clique em "Create API key".
  4. Copie o código (começa com AIzaSy...).
Abrir Google AI Studio ↗
⚡

2. Groq Cloud (Llama 3)

Ultra-Rápido & Grátis

Onde clicar no site:

  1. Entre com o Google ou GitHub.
  2. No menu da esquerda, clique em "API Keys".
  3. Clique no botão "Create API Key".
  4. Copie o código (começa com gsk_...).
Abrir Groq Cloud ↗
⚙️

3. Cadastrar no OmniRoute

Painel de Controle

Como salvar as chaves:

  1. Abra o painel com omniroute dashboard.
  2. Vá na aba "Providers".
  3. Cole a chave do Gemini ou Groq e clique em Save.
Abrir Painel Local (Porta 20128) ↗

6 🚀 Ligar o Motor e Rodar o Claude Code

Com as chaves cadastradas, vamos colocar tudo para rodar em 2 passos simples:

PASSO 5

Ligar o Motor do OmniRoute (Janela 1)

Nesta primeira janela do terminal, inicie o servidor:

PowerShell (Janela 1) 
omniroute serve
⚠️ Atenção: Esta janela vai ficar travada mostrando logs. NÃO FECHE ESSA JANELA! Ela precisa ficar aberta.
PASSO 6

Abrir a Segunda Janela e Rodar o Claude Code (Janela 2)

1. Abra uma nova janela do PowerShell (tecla Windows + powershell).
2. Entre na pasta do projeto e chame o claude:

PowerShell (Janela 2) 
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
claude
Resultado final com sucesso: O Claude Code abrirá mostrando o rostinho laranja e gratuitos with high effort pronto para você conversar!
