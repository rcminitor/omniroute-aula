Agentes de IA & OmniRoute no Laboratório

Guia prático e portal de laboratório sobre Agentes de IA, a realidade de custos em LLMs, infraestrutura de roteamento multi-provedor (OmniRoute), mitigação de erros de cota (429) e operação do Claude Code no terminal.

1 🚨 Guia Rápido de Sobrevivência (Leia antes de mexer no teclado!)

Se você nunca mexeu muito no terminal ou não tem computador em casa, não se preocupe! Guarde estas 4 regras de ouro:

🖱️ Regra 1: Como colar no terminal

Copie o código no botão roxo. Na tela preta (PowerShell), basta dar um clique com o botão direito do mouse que o texto cola sozinho.

🪟 Regra 2: O segredo das 2 janelas

O OmniRoute precisa de duas janelas pretas abertas: Janela 1 (motor ligado) e Janela 2 (conversa com a IA). Não faça tudo na mesma janela!

👻 Regra 3: A pasta invisível

Pastas com ponto na frente (ex: .claude) ficam invisíveis no Windows. Se você não vir a pasta no Explorer, ela NÃO sumiu, está oculta.

🟡 Regra 4: Texto amarelo não é erro

Avisos amarelos do npm warn são apenas informações. Você só deve se preocupar se o terminal fechar ou der uma mensagem vermelha.

2 📖 Dicionário do Aluno (Em linguagem simples)

Entenda o que são esses termos técnicos usando comparações da vida real:

Nome Técnico O que parece na vida real? O que ele faz no computador?
Agente de IA (Claude Code) Um estagiário de programação muito rápido. Ele lê seus arquivos, cria código e roda testes direto no computador.
OmniRoute Um roteador Wi-Fi inteligente. Fica na porta 20128 e escolhe a IA gratuita mais rápida para te responder.
API O garçom de um restaurante. Leva a sua mensagem até o computador da IA e traz a resposta de volta.
Tokens Contagem de palavras do SMS. É a quantidade de texto que a IA lê e escreve por segundo.
Fallback (Transbordo) O plano B da caixa d'água. Se o Gemini bater o limite gratuito, a chamada pula pro Groq sozinho sem travar.

3 💸 A Falácia do "Almoço 100% Grátis" em IA

Muitos tutoriais na internet prometem "Use Claude Code 100% grátis para sempre via OpenRouter". Na prática, isso é uma falácia de marketing.

⚠️ Por que o 100% grátis na nuvem trava?

Rodar IA de ponta exige computadores gigantescos com placas de vídeo (GPUs H100) que custam fortunas e gastam muita eletricidade. O OpenRouter disponibiliza modelos :free apenas para testes rápidos (20 a 50 requisições por dia). Quando um agente autônomo executa um loop de tarefas, ele faz 40 chamadas em 5 minutos e esgota a cota do dia inteiro, gerando o Erro 429.

Abordagem Custo Médio Estabilidade Veredito
Modelos :free na Nuvem R$ 0,00 Baixa (Erro 429 constante) Frustrante para uso diário em agentes.
Modelos Locais (Ollama) R$ 0,00 real Alta (Roda na sua RAM) Excelente para privacidade e sem limite de requisições.
Pay-as-you-go Ultrabarato R$ 5 a R$ 15 / mês Máxima (Sem bloqueios) Melhor custo-benefício (DeepSeek / Gemini Flash).

4 🔄 Anatomia do Erro 429 & Roteamento em Cascata (Fallback)

O código HTTP 429 (Rate limit exceeded: free-models-per-day) ocorre quando o limite diário da sua conta do OpenRouter acaba. Esse limite é aplicado à sua chave inteira — portanto, alternar entre dois modelos gratuitos na mesma conta não resolve.

O Fluxo de Contingência (Fallback Real)

A solução definitiva é configurar múltiplos provedores independentes no OmniRoute em ordem de prioridade (estratégia fill-first):

1
Google Gemini (Google AI Studio)

Cota gratuita oficial e generosa direto da Google.

▼ (Se bater limite 429)
2
Groq Cloud (Llama 3.3 70B)

Inferência ultra-rápida em chips LPU dedicados.

▼ (Se atingir limite)
3
DeepSeek / OpenRouter com Saldo Mínimo (Centavos)

Rede de segurança que conclui a tarefa custando frações de centavos.

5 💻 Passo a Passo no Terminal (Pasta Única)

Siga os passos na ordem exata. Cada passo tem o botão de copiar e o que deve aparecer na sua tela.

PASSO 0 (OBRIGATÓRIO)

Testar se o Node.js e o npm existem no computador

Atenção: O comando npm não existe sozinho no computador; ele vem "de brinde" dentro do Node.js. Antes de qualquer coisa, teste se o computador do laboratório já tem o Node instalado:

PowerShell - Teste de Verificação 
node -v
✅ Se apareceu um número (ex: v20.x ou v22.x):

O Node.js e o npm já estão instalados! Você pode pular direto para o Passo 2.

❌ Se deu texto vermelho (Comando não reconhecido):

O computador não tem Node.js. Instale com o comando abaixo:

PowerShell - Como Instalar o Node.js no Windows 
winget install OpenJS.NodeJS.LTS
⚠️ Regra de Ouro do Windows: Se você acabou de instalar o Node.js, feche a janela do PowerShell e abra uma nova para que o Windows reconheça o comando npm!
PASSO 1

Instalar o Claude Code e o OmniRoute

Com o Node.js verificado, instale os dois programas necessários via npm:

PowerShell 
npm install -g @anthropic-ai/claude-code
npm install -g omniroute
Resultado esperado: Várias mensagens e barras de download vão passar na tela e terminar com added N packages.
PASSO 2

Criar a Pasta do seu Projeto

Copie o comando abaixo e cole no seu terminal para criar e entrar na pasta da aula:

PowerShell 
mkdir C:\Users\$env:USERNAME\Projetos\meu-projeto-ia -Force
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
mkdir .claude -Force
Resultado esperado: O caminho do terminal vai mudar para PS C:\Users\...\Projetos\meu-projeto-ia>.
PASSO 3

Criar o arquivo de Proteção (.gitignore)

Esse arquivo protege você de enviar suas senhas para o GitHub sem querer:

PowerShell 
@'
.claude/settings.local.json*
*.env
*.log
*.sqlite*
'@ | Out-File -FilePath .gitignore -Encoding utf8
PASSO 4

Configurar o Claude Code para usar o OmniRoute

Cole este comando para criar a configuração que conecta o Claude Code ao OmniRoute local (porta 20128):

PowerShell 
@'
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "sk-omniroute-local-token",
    "ANTHROPIC_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gratuitos",
    "CLAUDE_CODE_SUBAGENT_MODEL": "gratuitos",
    "ENABLE_CLAUDEAI_MCP_SERVERS": "false"
  },
  "model": "gratuitos",
  "disableClaudeAiConnectors": true
}
'@ | Out-File -FilePath .claude\settings.local.json -Encoding utf8
Resultado esperado: O comando roda em silêncio (sem mensagem de erro).
PASSO 5

Ligar o Motor do OmniRoute (Janela 1)

Nesta primeira janela do terminal, inicie o servidor do OmniRoute:

PowerShell (Janela 1) 
omniroute serve
Atenção: Esta janela vai ficar travada mostrando logs. NÃO FECHE ESSA JANELA! Ela precisa ficar aberta.
PASSO 6

Abrir a Segunda Janela e Chamar o Claude Code (Janela 2)

1. Abra uma nova janela do PowerShell (tecla Windows + powershell).
2. Entre na pasta do projeto e rode o claude:

PowerShell (Janela 2) 
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
claude
Resultado final com sucesso: O Claude Code abrirá mostrando o rostinho laranja e gratuitos with high effort pronto para você conversar!

6 🔑 Onde Pegar as Chaves de API (Depois de Montar a Estrutura)

Agora que a estrutura do seu projeto já está criada, conecte as Chaves Gratuitas no OmniRoute para que a IA tenha múltiplos provedores de contingência:

G

1. Google Gemini API

100% Gratuito Oficial

Onde clicar no site:

  1. Faça login com seu Gmail normal.
  2. Clique no botão azul "Get API key".
  3. Clique em "Create API key".
  4. Copie o código (começa com AIzaSy...).
Abrir Google AI Studio ↗
⚡

2. Groq Cloud (Llama 3)

Ultra-Rápido & Grátis

Onde clicar no site:

  1. Entre com o Google ou GitHub.
  2. No menu da esquerda, clique em "API Keys".
  3. Clique no botão "Create API Key".
  4. Copie o código (começa com gsk_...).
Abrir Groq Cloud ↗
⚙️

3. Painel OmniRoute

No seu próprio PC

Como colar as chaves:

  1. Abra o painel com omniroute dashboard.
  2. Vá na aba "Providers".
  3. Cole a chave do Gemini ou Groq e clique em Save.
Abrir Painel Local (Porta 20128) ↗

7 ⚡ Claude Code: Comandos e Boas Práticas

Ao utilizar o Claude Code conectado via OmniRoute, algumas práticas evitam lentidão e consumo desnecessário de contexto:

* Transfiguring... (Processando)

É a animação normal do Claude Code indicando que ele está processando a resposta da LLM e avaliando as ferramentas do projeto.

Cuidado com MCPs em Excesso

Servidores MCP sem autenticação ou em excesso podem enviar até 150.000 tokens em uma saudação simples, atrasando a resposta.

Comandos no Terminal do Claude Code 
/       # Abre o menu interativo com todas as opções
/model  # Exibe o modelo ou combo ativo (ex: gratuitos)
/mcp    # Gerencia e desativa servidores MCP pesados
/clear  # Limpa o histórico da sessão e acelera as respostas
/cost   # Mostra o consumo de tokens e estatísticas
