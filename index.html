Agentes de IA & OmniRoute no Laboratorio

Roteiro pedagogico completo para a aula de laboratorio: entenda o que sao agentes de IA, por que o "gratis ilimitado" nao existe, como instalar as ferramentas, ligar o servidor, cadastrar suas chaves e finalmente executar o Claude Code com roteamento automatico de fallback.

1 O que e um Agente de IA? (Entenda antes de instalar)

Antes de tocar no teclado, voce precisa entender o que vamos fazer hoje. Nao e usar um chatbot normal. Hoje vamos montar um sistema de agentes autonomos que age, nao apenas responde.

Analogia: Chatbot vs. Agente

Um chatbot comum (ex: ChatGPT na tela) e como um chef que te manda a receita por mensagem de texto. Voce que tem que ir para a cozinha e cozinhar.

Um Agente de IA e como um chef que entra na sua cozinha, abre a geladeira, le os ingredientes, acende o fogao, cozinha o prato e coloca na mesa. Voce so pede: "Quero uma massa ao molho pesto" e espera pronto.

As 3 ferramentas que vamos usar hoje:

Agente Principal

Claude Code

E o agente que fica na "tela preta" (terminal/PowerShell). Voce conversa com ele em portugues, pede para criar codigo, analisar arquivos, debugar erros - e ele age diretamente no computador: cria pastas, escreve arquivos, roda testes, tudo sozinho.

📌 Instalado via npm e roda no terminal.
📌 Por padrao usa a API paga da Anthropic - e por isso que vamos usar o OmniRoute!

Roteador Local

OmniRoute

E um programa que fica rodando no seu computador como um servidor local (na porta 20128). Ele intercepta os pedidos do Claude Code e os redireciona para provedores de IA gratuitos, como Google Gemini e Groq.

📌 Tem um painel visual no navegador (localhost:20128).
📌 Faz fallback automatico: se um provedor travar, muda para o proximo.

Provedores Externos

Google Gemini & Groq

Sao os servidores de IA que realmente "pensam". O Gemini fica na nuvem da Google e o Groq em chips ultra-rapidos nos EUA. Ambos tem cotas gratuitas oficiais suficientes para usar em sala de aula.

📌 Voce precisa criar uma conta gratuita em cada site.
📌 Cada um te da uma chave de API (senha secreta) que vamos configurar.

Como tudo se conecta (fluxo completo):

→
Voce digita no Claude Code (terminal)

Exemplo: "Crie uma pagina HTML com formulario de login"

▼ Claude Code envia o pedido para localhost:20128
→
OmniRoute (rodando na sua maquina, porta 20128)

Recebe o pedido, olha qual provedor esta disponivel, e encaminha.

▼ Encaminha para Google Gemini (1a prioridade)
→
Google Gemini / Groq Cloud (IA na nuvem)

Processa o pedido e devolve a resposta em segundos.

▼ Retorna para o Claude Code → Claude age no seu computador
✅
Resultado: arquivo criado no seu computador!

Claude cria o arquivo index.html, escreve o codigo - tudo sozinho.

2 A Falacia do "Almoco 100% Gratis" & Erro 429

Muitos videos na internet prometem "Claude Code ilimitado e 100% gratis para sempre". Na pratica, isso e uma ilusao tecnica. Voce precisa entender por que antes de frustrar-se no laboratorio.

Por que o "100% gratis na nuvem" trava? (O Erro 429)

Rodar Inteligencia Artificial exige supercomputadores com placas de video caras (GPUs H100 da NVIDIA). Plataformas como o OpenRouter dao modelos :free apenas para pequenos testes. Como o agente faz 40+ chamadas em 5 minutos, a cota diaria zera e aparece o erro:

API Error: Request rejected (429) - Rate limit exceeded: free-models-per-day

A Solucao da Aula: Roteamento com Fallback

Para a sua aula nao travar, usamos o OmniRoute conectando multiplos provedores independentes. Se a cota de um zerar, ele pula para o outro automaticamente:

1º
Google Gemini (Google AI Studio) Cota gratuita oficial e generosa direto da Google
Principal
▼ Se o Gemini bater o limite 429...
2º
Groq Cloud (Llama 3.3 70B) Assume imediatamente em chips ultrarapidos - resposta em menos de 1 segundo
Fallback
▼ Se ambos estiverem no limite...
3º
DeepSeek / Modelo de Centavos (opcional) Rede de seguranca - custo de centavos para quem tiver R$ 5 de credito
Emergencia

Resumo para a aula: Voce vai criar uma conta gratuita no Google AI Studio e no Groq, pegar a chave de cada um e cadastrar no OmniRoute. Isso cria o combo que nunca trava - mesmo que uma cota estoure, o outro assume na hora.

3 Dicas de Sobrevivencia (Antes de Mexer no Teclado)

Se voce nunca usou o terminal ou nao tem computador em casa, guarde estas 4 regras praticas:

Como colar no terminal

Clique no botao roxo de copiar. Na tela preta (PowerShell), basta dar um clique com o botao direito do mouse que o texto cola sozinho.

O segredo das 2 janelas

O OmniRoute precisa de duas janelas pretas abertas: Janela 1 (motor ligado) e Janela 2 (conversa com o Claude). Nao tente fazer tudo em uma janela so!

A pasta invisivel

Pastas com ponto na frente (ex: .claude) ficam invisiveis no Windows. Se voce nao vir a pasta no Explorer, ela NAO sumiu, esta oculta.

Texto amarelo nao e erro

Avisos amarelos do npm warn sao apenas informacoes. Voce so deve se preocupar se o terminal fechar ou der uma mensagem vermelha.

4 Mao na Massa: Instalando Ferramentas e Criando o Projeto

Agora vamos comecar a preparar o computador. Siga os passos na ordem exata:

4.0 Verificacao de Pre-requisitos

Abrir o PowerShell e Testar se o Node.js existe

Como Abrir o PowerShell
Pressione a tecla Windows no teclado → Comece a digitar powershell → Clique em "Windows PowerShell" nos resultados. Uma janela preta vai abrir.

Dentro da janela preta, copie e cole o comando abaixo e pressione Enter:

PowerShell - Teste de Verificacao 
node -v
Se apareceu um numero (ex: v20.x ou v22.x):

O Node.js e o npm ja estao instalados! Pule direto para o Passo 1.

Se deu texto vermelho (Comando nao reconhecido):

O computador nao tem Node.js. Instale com o comando abaixo:

PowerShell - Instalacao do Node.js 
winget install OpenJS.NodeJS.LTS
Atencao: Se voce acabou de instalar o Node.js, feche o PowerShell e abra de novo para ele reconhecer o npm.
4.1 Instalar Pacotes

Instalar o Claude Code e o OmniRoute

Instale os dois programas necessarios via npm:

PowerShell 
npm install -g @anthropic-ai/claude-code
npm install -g omniroute
Resultado esperado: Varios downloads vao passar na tela e terminar com added N packages.
4.2 Criar Pasta do Projeto

Criar a Pasta Isolada do Projeto

Copie e cole para criar a pasta da aula e a subpasta oculta .claude:

PowerShell 
mkdir C:\Users\$env:USERNAME\Projetos\meu-projeto-ia -Force
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
mkdir .claude -Force
Resultado esperado: O caminho do terminal vai mudar para PS C:\Users\...\meu-projeto-ia>.
4.3 Proteger Dados Sensíveis

Criar o arquivo de Protecao (.gitignore)

Gera o arquivo que impede que senhas e dados locais subam para a internet:

PowerShell 
@'
.claude/settings.local.json*
*.env
*.log
*.sqlite*
'@ | Out-File -FilePath .gitignore -Encoding utf8
4.4 Conectar ao OmniRoute

Configurar o Claude Code para usar o OmniRoute

Cria a configuracao que conecta o Claude Code ao gateway local (porta 20128):

PowerShell 
@'
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "sk-omniroute-local-token",
    "ANTHROPIC_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gratuitos",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gratuitos",
    "CLAUDE_CODE_SUBAGENT_MODEL": "gratuitos",
    "ENABLE_CLAUDEAI_MCP_SERVERS": "false"
  },
  "model": "gratuitos",
  "disableClaudeAiConnectors": true
}
'@ | Out-File -FilePath .claude\settings.local.json -Encoding utf8
Pronto! As ferramentas estao instaladas. Agora vamos ligar o servidor OmniRoute antes de continuar.

5 Ligar o OmniRoute (Fazer o Servidor Funcionar)

Antes de cadastrar as chaves ou usar o Claude, voce precisa ligar o servidor OmniRoute. Sem ele ligado, nada funciona. Este e o "motor" que precisa estar sempre rodando.

IMPORTANTE: O servidor precisa estar ligado em uma janela do terminal dedicada que voce NUNCA pode fechar enquanto esta usando o Claude Code. Pense nela como o motor de um carro - se apagar, o carro para.

5.1 Iniciar o Servidor OmniRoute

Iniciar o servidor OmniRoute

Abra uma nova janela do PowerShell (Windows + digitar powershell) e rode:

PowerShell (Janela 1 - Mantenha aberta!) 
omniroute serve
Esta janela vai ficar "parada" mostrando logs. Isso e normal. NAO FECHE essa janela!

Sinal de que funcionou: Voce vera na tela algo como Server started on http://localhost:20128. Quando aparecer isso, o motor esta ligado!

5.2 Acessar o Painel Visual

Abrir o Painel do OmniRoute no Navegador

Com o servidor ligado, abra seu navegador (Chrome, Edge ou Firefox) e acesse:

Abrir Painel OmniRoute (localhost:20128) ↗
O que voce vai ver na tela do painel
Uma interface escura com o logo do OmniRoute. No menu da esquerda voce vera as opcoes: Dashboard, Providers, Combos, e Logs. Isso significa que o servidor esta funcionando corretamente!

6 Pegar as Chaves Gratuitas de API

Agora que o servidor esta rodando, vamos buscar as chaves nos sites oficiais. Cada chave e como uma senha que autoriza o OmniRoute a usar os modelos de IA.

Dica: Abra os dois sites abaixo em abas separadas do navegador, copie as chaves e deixe um bloco de notas (Notepad) aberto para colar temporariamente. Voce vai precisar das duas chaves no proximo passo.

G

1. Google Gemini API

100% Gratuito Oficial

Onde clicar no site (passo a passo):

1
Acesse o site e faca login com sua conta Gmail (botao azul no canto superior direito).
2
No menu da esquerda, clique em Get API key
3
Clique no botao Create API key que aparece no centro da pagina.
4
Selecione "Create API key in new project" e clique em Create.
5
Copie o codigo que aparece (comeca com AIzaSy...). Guarde no Bloco de Notas!
Abrir Google AI Studio ↗
⚡

2. Groq Cloud (Llama 3)

Ultra-Rapido & Gratis

Onde clicar no site (passo a passo):

1
Acesse o site e clique em Sign In no canto superior direito. Use Google ou GitHub para entrar.
2
No menu lateral da esquerda, clique em API Keys.
3
Clique no botao Create API Key na parte superior.
4
Em "Name", escreva aula-ifce e clique em Submit.
5
Copie o codigo (comeca com gsk_...). Salve no Bloco de Notas - ele so aparece uma vez!
Abrir Groq Cloud ↗

7 Cadastrar Provedores e Criar o Combo no Painel

Agora vamos entrar no painel do OmniRoute, colar as chaves e criar o Combo de Fallback. Lembre-se: o servidor precisa estar ligado (Secao 5)!

Abrir Painel OmniRoute (localhost:20128) ↗
7.1 Cadastrar Provedores

Entrar na tela de Providers e Cadastrar os Provedores

Voce esta no painel do OmniRoute
Olhe para o menu lateral da esquerda. Voce vera opcoes como Dashboard, Providers, Combos, Logs. Clique em Providers.
1
Na tela de Providers, clique no botao + Add Provider.
2
No campo Provider Type, selecione "Google Gemini" no menu suspenso.
3
No campo API Key, cole sua chave do Google (comeca com AIzaSy...).
4
Clique no botao Save ou Connect. Um icone verde ✅ deve aparecer indicando que esta conectado.

Agora repita o processo para o Groq: Clique novamente em + Add Provider, selecione "Groq", cole a chave gsk_... e clique em Save.

7.2 Criar o Combo

Criar o Combo "gratuitos" (Roteamento com Fallback)

Navegue para a tela de Combos
No menu lateral da esquerda, clique em Combos.

O combo e a lista de prioridades que faz o transbordo automatico se um provedor travar:

1
Clique no botao + Create Combo.
2
Em Combo Name, digite exatamente: gratuitos (tudo minusculo, sem espaco).
3
Em Strategy, escolha: fill-first (tenta o 1o, se falhar pula pro 2o).
4
Clique em + Add Model e selecione/digite gemini-2.0-flash (1a prioridade).
5
Clique novamente em + Add Model e selecione/digite groq/llama-3.3-70b-versatile (2a prioridade).
6
Clique em Save Combo e depois ative-o clicando no toggle para "Enabled".
Resultado esperado: O combo "gratuitos" aparece na lista com status Active/Enabled. Isso significa que o roteamento automatico com fallback esta configurado!
7.3 Testar Provedores

Testar se os Provedores estao Respondendo

Antes de abrir o Claude Code, rode este comando em uma nova janela do PowerShell:

PowerShell - Teste de Saude dos Provedores 
omniroute providers test-all
Resultado esperado: Deve aparecer OK main (gemini): provider test passed e OK main (groq): provider test passed em verde!

8 Ligar e Rodar o Claude Code

Com tudo testado e verificado, vamos colocar tudo para rodar em 2 passos simples:

Verifique antes de continuar: A Janela 1 (com omniroute serve) ainda esta aberta? Se tiver fechado por acidente, abra novamente e rode omniroute serve antes de continuar.

8.1 Abrir Nova Sessao

Abrir uma Nova Janela e Rodar o Claude Code

1. Pressione Windows e abra uma nova janela do PowerShell (a Janela 1 com o OmniRoute deve continuar aberta!).
2. Nesta nova janela, entre na pasta do projeto e chame o claude:

PowerShell (Janela 2 - Para conversar com Claude) 
cd C:\Users\$env:USERNAME\Projetos\meu-projeto-ia
claude
Resultado final com sucesso: O Claude Code abrira mostrando o rostinho laranja e gratuitos with high effort - pronto para voce conversar!
8.2 Primeiro Teste

Primeiro Teste: Pedir ao Claude para Criar um Arquivo

Com o Claude Code aberto e funcionando, vamos fazer um primeiro teste simples. Digite o pedido abaixo e pressione Enter:

Terminal Claude Code - Digite isso 
Crie um arquivo chamado ola.txt com o texto "Ola, Agente! Funcionou!" dentro.

Observe o que vai acontecer: O Claude vai agir autonomamente - voce vera ele criar o arquivo, escrever o conteudo e confirmar. Depois abra o Explorador de Arquivos e procure o arquivo ola.txt na pasta meu-projeto-ia para confirmar!

Como deve ficar o terminal do Claude Code funcionando:

Windows PowerShell - Janela 2 (Claude Code Funcionando)
┌───┐
│o.o│ Claude Code v2.1.278
└───┘ gratuitos with high effort · API Usage Billing
~\Projetos\meu-projeto-ia
> ola
* Transfiguring... (processando seu pedido)

Ola! Como posso ajudar voce no seu projeto de programacao hoje?

auto mode on (shift+tab to cycle) · esc to interrupt · / for commands

Comandos que voce vai usar durante a aula:

* Transfiguring...

Processando: E a animacao normal do Claude Code indicando que ele esta processando. Aguarde - nao aperte nada!

/clear

Ficar mais rapido: Se a conversa comecar a demorar, digite /clear no terminal para limpar o historico e acelerar as respostas.

/exit

Sair: Para fechar o Claude Code, digite /exit ou pressione Ctrl+C.

omniroute providers test-all

Verificar status: A qualquer momento, rode este comando em uma nova janela para checar o status dos provedores.
